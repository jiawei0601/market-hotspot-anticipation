# 共同封裝光學（CPO）與先進封裝物理變革可行性評估報告：超前 18-24 個月 Feynman_Next 世代供應鏈價值量洗牌與非共識正確路徑

**致：投資審查委員會（Investment Committee）**  
**報告主題：CPO_Optical_Transceiver 板塊自 Vera_Rubin $\rightarrow$ Feynman $\rightarrow$ Feynman_Next 世代演進之物理極限、Content Value 劇變與預期差定量分析**

---

## 執行摘要：系統級封裝物理介面重構與去中間化風險

隨著半導體製程逼近物理極限，晶片架構的演進已從單純的電晶體微縮，轉向系統級封裝（SiP）的物理介面重構。本報告聚焦於超前 18-24 個月之 **Feynman_Next** 世代，評估兩大核心物理變革：
1. **傳輸介面的光電融合（CPO）由「分立式封裝」走向「晶圓級單晶/混合整合（Wafer-Level Monolithic/Hybrid Integration）」**。
2. **基板材質由「有機載板（ABF Substrate）」徹底過渡至「玻璃基板（Glass Substrate with TGV）」**。

這兩大物理變革將引發供應鏈內容價值（Content Value, CV）的劇烈洗牌。本報告旨在揭示：市場當前高共識度之 CPO 封裝標的，在 Feynman_Next 世代面臨之「去中間化（Disintermediation）」與價值量歸零風險；同時定量論證設備端如何憑藉高難度物理壁壘，實現 Content Value 的持續擴張。

## 一、 技術物理限制與超前 18-24 個月 (Feynman_Next) 洗牌框架

在 Feynman_Next 世代的極限物理架構下，傳統封裝、傳輸、基板與散熱方案均面臨物理瓶頸，推動技術路徑發生本質性轉移。

```
[Vera_Rubin 世代] ──> [Feynman 世代] ──> [Feynman_Next 世代 (18-24M)]
  ABF 有機載板          局部矽中介層          玻璃基板 (TGV)
  可插拔光模組          分立式 CPO 引擎       晶圓級單晶 CPO (COUPE)
  3D VC + 混合液冷      DTC 直接晶片液冷      浸沒式液冷 / 晶圓級微流道
```

### 1. 三代物理架構演進與關鍵瓶頸對比

| 物理維度 | 當前世代 (Vera_Rubin) | 下一代 (Feynman) | 下下一代 (Feynman_Next) - 18-24M |
| :--- | :--- | :--- | :--- |
| **封裝技術 (Packaging)** | CoWoS-S / CoWoS-L | CoWoS-R / CoWoS-DR | **FOPLP (面板級) / 3D Hybrid Bonding** |
| **傳輸介面 (Transmission)** | PCIe Gen 6 / Pluggable Optic | **CPO (分立式光學引擎)** | **Wafer-Level Monolithic CPO (COUPE)** |
| **基板材質 (Substrate)** | 高階有機載板 (ABF) | 有機載板 + 局部矽中介層 | **玻璃基板 (Glass Substrate with TGV)** |
| **散熱方案 (Cooling)** | 3D VC + 混合液冷 | Direct-to-Chip (DTC) 液冷 | **浸沒式液冷 (Immersion) / 晶圓級微流道** |
| **關鍵物理瓶頸** | 萬潤 (Underfill 溢膠控制), 辛耘 (微塵粒子清洗) | 聯鈞 (分立式光學耦合良率), 家登 (EUV Pod 污染控制) | **鈦昇 (TGV Laser 鑽孔精度), 弘塑 (玻璃高深寬比蝕刻與清洗)** |

### 2. 核心物理變革解析

*   **晶圓級單晶/混合光電整合（COUPE 技術）**：在 Feynman 世代，CPO 仍採用分立式光學引擎（Optical Engine）與外部雷射源（ELS），由後段封裝廠進行光電耦合。然而，進入 Feynman_Next 世代，為解決高頻傳輸損耗與寄生電容，光電轉換結構將直接在晶圓廠（Foundry）內部透過**矽光子晶圓級混合鍵合（Hybrid Bonding）**完成，將光學元件（PIC）與 ASIC 進行 3D 堆疊。此一物理變革將導致傳統分立式光學耦合需求被晶圓廠直接整合。
*   **玻璃基板（Glass Substrate with TGV）**：傳統 ABF 有機載板在高溫、多晶片堆疊（Multi-die Stacking）環境下易發生翹曲（Warpage），且無法提供高密度訊號傳輸。玻璃基板憑藉極低膨脹係數與高平整度成為唯一解方。其核心物理挑戰在於 **TGV（Through Glass Via，玻璃通孔）** 的製作，要求在微米級孔徑下實現無裂紋的高速雷射鑽孔與高深寬比金屬化。

  30 ┼─────────────────────────────────────────── 弘塑 (10 -> 18 -> 26)
     │                                            [無替代風險]
  20 ┼─────────────────────────── 鈦昇 (1 -> 8 -> 18)
     │                            [無替代風險]
  10 ┼─────────── 聯鈞 (4.5 -> 14 -> 8)
     │            [高替代風險]
   0 ┼───────────┴────────────┴────────────
         Vera_Rubin     Feynman     Feynman_Next

*   **物理失效與去中間化路徑**：Feynman_Next 導入晶圓級單晶光電整合後，光電轉換晶片直接在晶圓廠端進行 3D 堆疊與封裝。傳統由光模組封裝廠進行的分立式光學耦合與中介層封裝需求被晶圓廠直接「去中間化」。聯鈞的價值量將被嚴重侵蝕，退回至僅提供邊緣非核心測試或低階耦合元件的角色。
