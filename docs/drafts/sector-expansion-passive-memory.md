### Segment 判定原則

被動元件板塊本輪查證的 10 檔候選股**全數判定為 `component`（元件製造本身）**，無一檔判定為 `downstream`。理由：

- 九豪（陶瓷基板，電阻的載體/半成品）仍歸類為 `component`，因為它是被動元件製造鏈的上游關鍵環節而非通路/貿易商角色。
- 若未來查證到單純代理國際大廠（村田、TDK、Vishay）被動元件產品、僅做通路銷售不涉及自製的公司，應歸類為 `downstream`；本輪 10 檔候選中沒有這類角色，需另一輪查證才能補入。

### Segment 判定原則（component vs downstream）

**判定原則**：`component` = 自己設計/製造記憶體晶片或顆粒本身（IC設計公司出自研產品、或擁有晶圓產能做DRAM/Flash製造，或記憶體晶圓代工）；`downstream` = 買入他廠顆粒後組裝成模組/SSD/隨身碟等成品並銷售，自己不產出顆粒本身。

逐檔判定：

- **2408 南亞科 → component**：DRAM 原廠，擁有晶圓廠自產 DRAM 顆粒，法說會揭露先進製程(1C/1D/EUV)研發與新廠資本支出。
- **2344 華邦電 → component**：DRAM/NOR Flash/NAND Flash 製造商，擁有晶圓產能(高雄廠)，CMS 客製化記憶體亦為自製顆粒後依客戶規格封裝。
- **2337 旺宏 → component**：NOR Flash/NAND Flash IC 製造商，擁有自有晶圓廠，資本支出用於自建產能而非採購顆粒。
- **8299 群聯 → component**：核心本業是 NAND Flash 控制IC設計——管理層在法說會中明確區分「若只做模組，毛利率個位數；群聯提供控制晶片+韌體+ASIC設計服務」，故歸類為 component（控制IC設計本身，不是組裝顆粒的 downstream 角色）。
- **3260 威剛 → downstream**：DRAM/SSD 模組廠，法說會明確說明其庫存來自「原廠採購」，即買南亞科/華邦電/國際大廠的顆粒來組裝成模組銷售，不具晶圓產能。
- **8271 宇瞻 → downstream**：業務結構明講是「記憶體模組」(工控/消費)，靠採購顆粒後模組化。
- **4967 十銓 → downstream**：法說會明講依賴「與南亞科、NAND廠20-30年合作關係取得料源」，即向原廠採購顆粒後做成模組銷售，屬品牌模組商。
- **2451 創見 → downstream**：明確定位「記憶體模組大廠」，內湖工廠 SMT 產線做模組組裝(非晶圓製造)，與上游簽 LTA 長約採購顆粒。
- **6770 力積電 → component**：晶圓代工廠，DRAM/Pseudo SRAM/SLC NAND 皆為晶圓代工製造服務（幫南亞科/華邦電/其他IC設計公司代工生產記憶體晶圓），屬於顆粒製造環節，非組裝模組——晶圓製造本身不算 equipment，記憶體顆粒製造/IC設計/代工都算 component。
- **6531 愛普* → component**：IC設計公司，自研 IoTRAM/ApSRAM/S-SiCap 產品，屬記憶體相關 IC 自行設計銷售，非組裝他廠顆粒。
- **5351 鈺創 → component**：記憶體IC設計商，與南亞科合資做AI記憶體「設計服務」，本業是IC設計而非模組組裝。
- **3006 晶豪科 → component**：利基型記憶體IC設計商(Fabless模式)，自行設計後委外晶圓代工生產，屬IC設計本業非模組組裝。
- **5289 宜鼎 → downstream**：工控記憶體模組廠，明確定位「100%鎖定工控/醫療/自動化/5G/邊緣AI」的模組整合方案供應商，DRAM/Flash-SSD皆為採購顆粒後模組化，非自製顆粒。

**彙總**：component 8 檔（2408、2344、2337、8299、6770、6531、5351、3006）、downstream 5 檔（3260、8271、4967、2451、5289）。

### 誠實聲明（本節弱點）

1. **Wayback 存檔流程有波折**：查證 subagent 因環境限制無法直接呼叫 `web.archive.org`（WebFetch 工具層級拒絕），此步驟改由主對話用 curl 補做，過程中第一次呼叫拿到舊快照（`20260128160714`），第二次呼叫才產生新快照（`20260704110518`）；已用 curl 驗證新快照 HTTP 200 且內容含「記憶體」字樣。
2. **法說會證據多為二手轉述**：本輪查證的法說會重點絕大多數來自財經媒體（鉅亨網、CMoney投資網誌、口袋學堂、StockFeel、富果法說會備忘錄、vocus方格子等）對法說會內容的整理轉述，並未逐一核對 MOPS 法說會簡報原文 PDF 或逐字稿全文。轉述內容具體、多方來源交叉一致，但嚴格來說屬於「E1事件的E3層轉述」，建議之後應直接下載 MOPS 簡報或年報 PDF 做最終核對。
